# Analyst Chat — Feature Documentation

## What is it?
A conversational interface embedded in the PathTracer dashboard that 
allows security analysts to query the database using plain English 
instead of manually filtering tables or writing SQL.

## Why does it matter?
Traditional IDS dashboards require the analyst to already know what 
they're looking for. Analyst Chat inverts this — the analyst asks a 
question and the system finds the answer in the data automatically.

This is the difference between a dashboard that shows data and a 
system that answers questions.
